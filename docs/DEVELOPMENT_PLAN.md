# CRIS REA 开发计划

首要科研流程为母相 CIF + k / IR / OPD → 子群、完整归一化模式及导出。
当前可用入口、范围和限制以 README 为准；实测及已完成修复见 PHASE2_VALIDATION。
本文件仅维护剩余工作；不把一个有限案例相符扩展为全部官网能力验收。

## 待修的程序漏洞

- 没有本轮已复现但未修复的生产缺陷；新发现需保存最小反例。
- 原始工具输出诊断仍为有限识别规则。结构化流程通过精确协议解析和不变量进一步
  防止静默接受，但不能证明不存在其他官方版本/输入错误格式。

## 待执行的优化计划

### 1. 母相 IR 分解和官网模式约定

现有基完整覆盖 H 不变的位移/均匀对称应变空间，但列可混合母相 IR。
后续需从通用表示数据库或充分精度的官方接口取得表示矩阵与投影，不使用官网案例
模式作计算系数；解决平移子格不被全 G 保持时的表示作用域，再按 IR、副本和畴分块。
需给出共轭/实化、重复表示、正交化和规范选择的可审查推导。

验收：每块的群变换性质、角色重数、直和维数和全空间完备性，含非零 k、心化和多副本
反例。完整读审当前官网应变/As/Ap约定后另行实现兼容导出；不把 Kelvin 基改名为官网基。

### 2. k / IR / OPD 枚举与星臂核验

当前需要用户选择已有的单个 IR 和命名 OPD，独立参数数目由官方 k 表达式检查。
尚未提供浏览式候选枚举、任意向量 OPD 或多主 IR；名义 k 代表不能替代实际活跃臂。
需把精确表示矩阵的 D(g)η=η 与所求稳定子、平移相位逐项连接并验证，枚举器明确
离散域、连续域、边界及有限搜索条件，不能用有限采样声称穷尽。

### 3. 输入标准化与科研数据域

在不覆盖原始 CIF 的前提下，支持显式、有依据的 setting/原点/基变换和 FINDSYM
标准化；保留用户容差与全部映射。特殊分数位置、ESD、近似实验结构理想化须有独立
合同，不能靠增大精确匹配容差吸附。扩展部分占位、磁性、调制/不公度输入需分别推导。
增加实际课题组输入的独立验证，当前自构几何不能冒充实验数据。

### 4. 对照覆盖与科研格式

以同一独立输入、先本地冻结再官网读取的流程扩展官网比较。
优先心化 H 的官方原胞归一化、非零 k、应变、畴和多副本；
网站模式 CIF、ISOVIZ、振幅拟合和其他 Method 当前未提供兼容出口。
任何新增比较器只能读取冻结结果，不导入或启动生产求解、不回填答案。

### 5. 工程与完整逆向

- 逐字段恢复数据库秩、Fortran 维度/顺序与整数编码，连接更多读取器及数值核。
- PHP 实际后端调用仍需获许可的源码或服务端受控日志；浏览器协议不能证明进程命令。
- 当前锁为同一进程同一项目内串行；如需多进程队列或局域网部署，另设运行协调和权限合同。
- 优化有理群闭包和稠密投影性能前保留现有不变量及边界；超预算必须拒绝，不能静默截断。
