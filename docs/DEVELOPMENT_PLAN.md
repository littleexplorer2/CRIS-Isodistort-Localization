# CRIS REA 开发计划

首要科研目标：母相结构 + 用户选择的 k / IR / OPD → 子群与畸变模式。
已实现能力及用户入口以根 README 为准；本文件只维护未完成工作和验收条件。

## 待修的程序漏洞

- 暂无已知且未经修复的包装层缺陷。官方进程的零退出码不能表示输入合法；
  当前诊断识别仅覆盖已见错误格式，仍可能漏掉其他领域错误。
  后续若发现新格式，应保留最小真实反例并补充通用诊断，不能按材料名判错。
- 官方 FINDSYM 的短输入文件名约束由包装层适配。不要恢复直接传长绝对文件名；
  更换官方版本后需重新验证。

## 待执行的优化计划

### 1. 固定母相与坐标合同

明确 CIF 解析、空间群 setting、晶格度量、分数坐标、占位、原子标签和周期边界。
对普通空间群先支持明确列举的输入域，拒绝歧义或未支持的磁性/调制输入。
如调用 FINDSYM 标准化，应保留用户原始输入和显式容差，并同时输出坐标与晶格变换；
不能把官网生成的 setting 或映射回填为本地输入。

完成条件：从不同但等价的晶胞表达得到协变的结构；原子数、重数、晶胞体积和
正逆坐标变换一致。容差与单位有出处，边界输入能给出诊断。

### 2. k、IR 和 OPD 的本地枚举及选择

逐项追踪官方数据读取器、常数编码、k 星与表示构造，区分离散 k 标签和连续参数。
先固定公开命令能提供的输出合同，再决定哪些步骤直接调用官方程序，哪些需独立实现。
不将官网候选列表或有限参数采样包装成完整枚举器。

完成条件：可由母相与用户 k 输入本地产生合法候选，具有参数范围、精度和不支持状态；
用群闭包、表示乘法、维数和基变换检验，而不只检查一个候选计数。

### 3. 子群、晶格与原子轨道

将 `D(g)η=η` 的稳定子条件连接到空间群操作、平移晶格和新胞原子映射。
明确表示基与空间坐标基的区别、超胞指数和原点约定。

完成条件：空间群/平移部分闭包；指数和重数一致；原子映射可逆；
非零 k 的相位与晶格对偶关系可核查。

### 4. 完整模式基、度量与振幅

追踪投影、独立向量选择、应变与位移组合及官方归一化约定。
先完成普通三维、单 k、位移模式的明确子集，再扩展应变、占位、磁性和多 k。
只有推导和独立检验齐备后才能提供“归一化完整模式”导出。

完成条件：自由度计数、群变换性质、相关度量下的正交/归一、振幅与结构正逆变换、
单位一致性，以及能区别错误算法的反例均通过。所有近似具有误差依据和适用域。

### 5. 独立官网对照与科研导出

固定独立来源输入后先运行本地链并冻结结果，最后由只读比较器读取官网结果。
按双方合同比较子群、基变换、原点、原子映射、模式张成空间、归一化和振幅；
简并模式可有基变换自由度，不能只按逐列相等判定，也不能无依据放宽容差。

完成条件：证据记录输入/程序/数据库/配置/输出指纹、实际读取资源和明确的覆盖域；
计算链不读取官网参考。通过后才实现供课题组使用的 CIF、模式和可视化导出。

## 待补的逆向证据

- 每个数据库字段的秩、数组维度、Fortran 顺序、整数编码和读取例程尚需逐项核对。
- 公开浏览器通信未暴露 PHP 服务端的实际调用代码。若需要证明与官网执行完全同构，
  应使用获许可的服务器源码或服务器侧受控日志，不能从网络字段猜测命令行。
- 有函数级证据也不等于所有算法已恢复；全程序类型、分支和数值误差仍需按科研合同审查。
