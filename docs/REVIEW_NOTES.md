# 独立工程审查记录

日期：2026-10-20。审查对象为 `cris_rea/` 三层实现、
`tests/test_local_contract.py` 和 `tests/test_webpage_races.js`。
审查者未修改生产代码；发现交给实现者修复后，重新读取冻结文件及验证证据。
本审查没有运行原 CRIS 全量测试，也没有写入原 CRIS。

## 已修复的可行动发现

1. **连续 ISO 提示符可隐藏零退出码错误。** 初版正则只允许一个 `*`，
   但真实 `evidence/native/runtime/iso-gm4minus-p1/stdout.txt` 已显示多个
   无输出命令形成连续提示符。错误紧随这些提示符时会被漏判。现已允许
   连续提示符，并新增 `***Syntax error` 的最小反例。显式错误转换为
   `program_diagnostic`，保留真实退出码；没有把未匹配的文本解释为科学成功。
2. **目录链接可能在路径检查之前造成项目外写入。** 初版只检查
   `is_symlink()`，不充分覆盖 Windows junction。现于任何运行目录写入
   前校验 `runs.resolve()`，vendor 同样校验解析路径，并拒绝链接的
   `evidence.json`。Linux 链接反例确认拒绝发生在外部目标写入之前。
3. **文件读取竞态可能提交旧输入或覆盖新选择。** 初版在异步文件读取
   期间仍允许 Run。现使用选择版本号和读取状态：旧读取不能覆盖新文件、
   文本编辑或生成查询，读取未完成时不能执行。Node DOM 适配反例覆盖
   这些时序；它不是完整浏览器验收。
4. **不完整 HTTP 请求可能长期阻塞关闭。** 现设置 10 秒连接读取超时，
   不完整 body 返回 408；用缩短超时的实际本地 HTTP 用例验证。
5. **可选 Wyckoff 参数的非法值被静默省略。** 初版 HTTP 层用
   `value or None`，把 `0`、`False`、`[]` 等绕过后端类型检查。
   现直接交给后端，新增用例确认这些输入返回 400。

冻结后重读上述修复，没有留下本轮已识别但未处理的同类代码缺陷。
这不表示不存在其他缺陷。

## 当前工程边界

- 依赖方向为 frontend → application → backend；后端不导入界面或
  测试/官网比较器。受限 ISO 查询只序列化用户标签，不推断 k 参数、
  晶格、原子坐标、完整模式或归一化。
- HTTP 在调用业务前核对 loopback Host、端口、会话 token、Origin。
  body 有上限，拒绝 Transfer-Encoding。结果显示采用 `textContent`，
  页面设置 CSP、禁止框架嵌入与缓存。
- 文件上传通过 base64 传递原始字节；编辑文本明确改用 UTF-8。
  原始输入与 stdout/stderr 字节保存到运行目录，界面只显示有限预览。
- 每次运行使用唯一目录和复制的数据资源，核对复制指纹。默认参考日志、
  样例及官网答案不进入资源复制列表。运行后记录数据副本和产物指纹。
- Linux supervisor 使用新进程组；超时/输出上限终止进程组，正常主进程
  退出后也尝试清理同组后代。外层 supervisor 失联标为
  `supervisor_timeout`，没有谎称已经确认终止。
- 独立 cwd/ISODATA 副本并非操作系统沙箱。当前合同明确要求可信原始
  命令，不应把这套控制台解释为多租户执行服务。
- `completed_uninterpreted` 仅指进程结束，`scientific_validation`
  为 `not_performed`；非零退出、超时、输出截断和显式程序诊断不等于
  科学搜索“无解”。

## 仍需保持的证据边界

- 本轮测试不包含真实 NTFS junction 创建与拒绝；该修复的 Windows
  判断来自写入前 `resolve()` 不变量及代码审查。Linux 链接已实测。
- 进程组终止代码已审读，测试实测单个 Linux 进程超时；未单独实测
  多级后代、后代自行创建新 session 或 supervisor 崩溃情形。
- Node DOM 适配测试不是浏览器文件选择、下载或用户完整交互验收。
  真实浏览器及真实官方程序的运行记录应单列。
- 错误文本检测有明确有限模式；未匹配不意味着输入已被科学接受。
  多命令后真实 ISO 零退出码错误应保留实际 stdout 和状态证据。
- `source_code` 指纹是运行时磁盘源码快照。长驻 HTTP 进程启动后若源码
  被改动，不能仅凭该快照证明内存中已加载了新代码。代码冻结后的真实
  验收应重启服务，避免混淆版本。
- 以上工程复核没有验证空间群闭包、子群全集、表示、原子映射、模式
  归一化、数值容差或官网等价性；没有新增科学推导或近似公式。
