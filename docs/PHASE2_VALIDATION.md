# CIF → 子群 → 完整 H 不变模式 → 导出：本轮验证

日期：2026-10-20。全部实现、运行副本及证据写入桌面 CRIS_REA。
结果是有明确适用域的本地完整 H 不变位移/对称应变参数化，不是全部 ISODISTORT 功能、
逐母相 IR 模式列或全部空间群的验收。输入使用自构数学结构，不冒充课题组实验数据。

## 改动、科学含义与推导

新增普通 3D CIF 解析/精确轨道展开、官方 ISO 精确协议、k 参数数目检查、子群
晶格与群作用、Reynolds 完整模式、Kelvin 应变、振幅施加和五文件导出；
CLI、HTTP 和中文主流程共享同一应用入口。原始进程执行器继续返回未解释状态。

科学依据分开保存：官方行为及文献阅读范围见
`reference_library/MODE_CONTRACT.md`；本项目完整推导与代码步骤对应见
`reference_library/LOCAL_MODE_DERIVATION.md`，结构合同见
`reference_library/STRUCTURE_CONTRACT.md`，独立数学审查见 `reference_library/MODE_REVIEW.md`。
没有使用官网结果拟合系数、调容差或按材料/标签分支。

坐标为列晶格、Å、母相常规分数基变换及原点；极位移基按 H 常规胞全原子 Cartesian
RSS=1，非质量权重。均匀应变用 Kelvin/Frobenius，F=I+E 正定。刚性平移由群的
Fix(Q) 决定并单列保留。该约定不能直接接收官网振幅，具体单位和公式写入每次 JSON。
