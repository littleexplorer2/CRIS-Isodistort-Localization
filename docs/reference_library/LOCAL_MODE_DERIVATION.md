# 本地有限胞模式合同与推导

本文件为**本项目推导**，对应 `backend/modes/core.py`，不是官网列基恢复证明。
官方行为及已审读资料见 `MODE_CONTRACT.md`；CIF 精确表示见 `STRUCTURE_CONTRACT.md`。
实现范围是普通三维、全占位、ISO INTERNATIONAL NEW 常规设定、可公度有限子群胞。
只接受所给晶胞度量满足群等距作用的输入。不吸附坐标、拟合晶格或按材料调整参数。

## 1. 坐标、平移和心化

母相列晶格矩阵 A 的单位为 Å，分数坐标 x 无量纲。
ISO 打印的三个新基矢组成矩阵 C 的**列**；原点 o 在母相分数坐标中：

    x = o + C y,   A_H = A C.
    (R_H,t_H) = (C^-1 R_G C, C^-1(R_G o + t_G - o)).

这里变换前绝不将 ISO 子群操作的整平移去掉，否则非零 k 的相位会丢失。
变换后才以子群胞整数平移为模。矩阵、原点、Seitz 乘法、原子映射全部使用有理数。
母相与 H 的原胞矩阵均来自官方通用 `DISPLAY PARENT`，加入它们的三个平移生成元
后作有限闭包；不按空间群名称手填心化表。

记母相和子群常规胞中的点操作陪集数为 n_G、n_H，心化数为 c_G、c_H，
则总体群指数和原胞体积比为：

    [G:H] = |det C| n_G/n_H
    s = V_H,primitive/V_G,primitive = |det C| c_G/c_H.

分别与 ISO Index、Size 检查。原子枚举满足 N_H = N_G,conventional |det C|。
枚举为每个已展开母相原子 x 加整数 n，筛选 0 <= C^-1(x+n-o) < 1。
候选整数界由新胞八个顶点给出；没有任意距离截断。C 的每列还必须属于母相平移晶格。
导出胞中母相原胞数为 |det C|c_G，**不是** s（心化 H 时差一个 c_H）。

## 2. 完整位移空间

在固定的 H 常规胞内，位移向量 u 是 R^(3N) 中的极矢量，度量为未加质量权重的
笛卡尔内积。H/T_H 的每个操作产生原子置换 p_g 和正交矩阵
Q_g = A_H R_H A_H^-1，作用为 (D_g u)_(p_g(i)) = Q_g u_i。
代码逐项核查物种、原子来源、置换双射及 D 的置换复合部分。
Seitz 闭包精确成立，Q 的正交性在浮点界内检查。

    P = (1/|H/T_H|) sum_g D_g.

有限群平均给出 P^T=P、P²=P；其像恰为所有 D_g u=u 的向量：
不变向量被平均保留；任意平均结果左乘 D_h 只重排群求和。
所以没有必要用打印为三位小数的 ISO 投影向量拼接完整空间。
独立维数为角色平均

    dim Fix(D) = (1/|H/T_H|) sum_g [#被 p_g 固定的原子] tr(Q_g).

代码检查角色和为整数、等于 tr(P)、P 的幂等性和对称性。
对 P 的列作两次修正 Gram-Schmidt，检查列数等于角色维数，且 UU^T=P、U^TU=I。
这构造的是 H 不变空间，**不声称每列属于单一母相 IR/k/OPD，也不声称为动力学本征模**。
完整性仅限固定原子、固定有限平移胞及极位移自由度，不包含占位、磁性等。

## 3. 原点自由度与振幅

空间均匀平移中的允许部分为 Fix(Q)，由三维平均 (1/|H|)sum Q_g 求得。
若其正交基为 T，则在全胞中嵌入 T/sqrt(N)，从 P 扣除这一正交投影后构造内部模式。
保留并单独列出允许的刚性平移；其维数可为 0、1、2、3，不能一律减三。

    u = U a,   a = U^T u,   ||u||² = sum a_j².

列 U 无量纲，a 单位 Å，所有 N 个 H 常规胞原子共同 RSS 归一。
每母相原胞 RSS 为 ||a||/sqrt(|det C|c_G)。这是一套明确的本地约定；
尚未证明与当前官网逐模式标度、符号、简并列旋转或应变标度相同。

## 4. 均匀应变

使用对称张量的 Frobenius 内积 tr(E^T E)；Kelvin 六元基为
xx、yy、zz、(yz+zy)/sqrt(2)、(xz+zx)/sqrt(2)、(xy+yx)/sqrt(2)。
按 E -> Q E Q^T 的六维正交表示作相同群平均，得到完整 H 不变对称张量空间。
应变系数无量纲，欧氏范数等于张量 Frobenius 范数。
有限施加约定为对称伸长 F=I+E，要求正定：

    A' = F A_H,   r'_i = F(A_H y_i + u_i),
    y'_i = y_i + A_H^-1 u_i.

H 不变的 E 与每个 Q 交换，因此此变形保留所声明的 H；
零振幅或特殊振幅可有更高对称性。此处不是能量模型或小变形应力定律。
未审定的当前官网应变定义不能被本地 Kelvin 约定替代声称相同。

## 5. 数值、边界和导出

有理数部分无数值容差。浮点部分使用 binary64；
检查界为 `256 eps max(3N,|H|,6) max(1,cond(A_H)^2)`，
覆盖矩阵乘法、求逆及有限求和的保守累积误差。界大于 1e-7 时拒绝该病态晶胞，
不会提高容差通过。该界不是对任意输入的严格后向误差定理；通过值和条件数均留档。
CIF 误差括号保留为来源信息，计算使用中心值，不传播实验协方差；
近似等距但残差超过上述界时拒绝，而不是把实验误差解释为数值误差。

工程预算为至多 256 个胞内原子、384 个群操作、1,000,000 个平移候选；超限明确拒绝。
当前只支持正定向 C；非标准 setting、部分占位、不公度/磁性/调制输入不作静默转换。

CIF 优先写入完整 H 操作，原子循环只写每个 H 原子轨道的一个代表，避免全胞原子再被
完整操作展开造成重复。标准 CIF 数值不能直接写有理式 1/3，而有限小数可能破坏特殊
位点的精确约束。因此每次写出后重新解析检查重数、物种、全胞位置和晶格；若 H 非对称
单元无法通过，则明确改用 P1 全原子序列化，仍保留求得的 H 编号自定义标签及 JSON
中的精确 H/参考坐标。新序列化也必须通过检查。P1 是文件表示，不是重新求得的子群。
15 位小数的序列化检查界为分数坐标及逐项缩放晶格度量 1e-12，只检查写出误差，
不修改科学匹配容差，不吸附输入。输出分数坐标与 H 常规轴一致；晶胞长度角度从 A' 推得。
ASCII 模式 CSV 和 JSON 明确列行顺序、单位与基约定。未识别最大实际对称性。
位移、应变与原子数守恒适用；能量、动量守恒和声子频率不适用，因为没有力常数/动力学模型。

## 6. 验证对应

`tests/test_modes.py` 独立构造 P1、反演中心、反演原子对、C4、心化平移群和剪切超胞；
检查零空间、全部自由度、刚性平移维数、心化标度、非零平移胞的相反位移、RSS 和反变换，
CIF 只输出非对称单元，拒绝错胞/错指数/错 Size/错 setting/占位与非正定应变。
实际官方二进制与完整应用运行由 `tools/validate_mode_workflow.py` 另行记录。
这些代数反例不读取官网案例输出，不足以证明所有 230 群、全部 k 或官网列基等价。
