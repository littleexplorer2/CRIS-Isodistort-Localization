# 本地模式核心的独立数学复核

本记录对应 2026-10-20 的第二阶段实现审查，审查者只读生产代码。
这不是全部空间群、全部参数 k 的验收，也不是官网列基等价证明。
数学定义及来源的唯一入口为 `MODE_CONTRACT.md`；生产公式见
`LOCAL_MODE_DERIVATION.md`。

## 审查对象与结论范围

审读 `backend/modes/core.py`、`export.py`、`backend/iso_protocol.py`、
结构数据模型及相关定向测试，重点追踪输入坐标到导出坐标。
没有读取官网案例结果，没有向本地计算注入参考模式。

在显式有限胞、全占位、匹配的 ISO 设定及度量条件下，以下实现与推导一致：

- ISO 打印的基矢组成列矩阵；整数 Seitz 平移保留到新胞变换完成后。
  变换为 `C^-1 R C`、`C^-1(R o+t-o)`，符合主动作用约定。
- 心化平移由通用原胞矩阵列生成；母群和子群闭包、操作包含关系、
  群指数 `det(C)|G/TGconv|/|H/THconv|` 和原胞体积比各有检查。
- 超胞原子通过八顶点给出的严格包含盒枚举，再使用有理数半开胞筛选，
  不是任意距离搜索；超预算明确拒绝。
- 位移作用将源原子块旋转后写至目标置换块。有限群平均的像是完整 H
  不变位移空间，均匀平移只保留 `Fix(Q)`，不一律减三。
- 生产基是**子群常规胞全原子**笛卡尔 RSS 正交基。其归一化不同于官方
  原胞约定，但明确标记后是自洽且可逆的本地约定。
- Kelvin 六元基中的非对角张量为 `1/sqrt(2)`，张量 Frobenius 范数等于
  系数欧氏范数。`F=I+E` 要求正定，且 H 不变对称 E 与 Q 交换。
- 官方兼容 IR 列表仅作注释，未用于填入或拟合基系数。H 不变基不能据此
  取得逐列 IR、primary/secondary 或网站列名。

尚未发现上述核心公式的确定错误。角色平均和投影迹检查共享同一群表示，
不能称为完全独立的科学实现；它们与精确置换复合、等距性和基张成检查
共同构成有限输入下的验证。生产浮点界是声明的保守界，不是任意条件数下
严格舍入误差定理。

## 已复现的导出缺陷

最小反例不依赖材料数据：

    G = H = P3 (#143)
    generator: (x,y,z) -> (-y,x-y,z)
    a=b=4 Å, c=6 Å, alpha=beta=90°, gamma=120°
    one orbit representative: (1/3,2/3,1/7)
    all mode and strain amplitudes: zero

精确母相只有一个胞内原子，其 x/y 属于三折特殊位置。旧导出将坐标写成
`.333333333333333,.666666666666667,.142857142857143`，同时写完整 H 操作
和轨道重数 1。严格有理数重新展开得到 3 个相邻而不完全相同的位置，触发
`multiplicity_mismatch`。这不是增加小数位数就能消除的问题，因为有限
十进制不能精确表达 1/3。

证据为 `evidence/phase2/theory/review_export_roundtrip.json`，含当时源码
SHA-256、完整导出文本和真实异常。重现脚本同名 `.py`；它拒绝覆盖旧记录。
该结果只证明当时的 H-CIF 精确往返失败，不表示群投影失败。

不能通过任意放宽输入容差或静默吸附位置消除此反例。可审查的处理方式是：
把标准数值 CIF 的浮点表示边界明确记录，提供完整原子列表加 P1 的结构
序列化，并在独立 JSON 保留精确参考分数坐标、H 操作及模式。P1 是文件
展开约定；不能称计算找到了 P1，或把目标 H 的空间群号同时写作标准 CIF
空间群号。若另保留 H-CIF，应明确其近似特殊位置解释及消费者要求。

主代理收到反例后增加导出读回校验和必要时的 P1 全胞表示。独立调用修后
`checked_cif` 的记录追加为 `review_export_roundtrip_fixed.json`：
`roundtrip_succeeded`，一个原子，分数坐标残差 `3.33e-16`、度量残差 0，
表示为 `P1_full_cell`。这验证修复后的该反例，旧失败没有覆盖。
P1 仅为序列化表示，不能误称计算发现了 P1 的物理最大对称性。
