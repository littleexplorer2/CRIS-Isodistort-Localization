ISOTROPY for Linux

Download a version of the ISOTROPY Softward Suite that will run locally under a Linux operating system. This version of the suite includes the current versions of ISOTROPY, FINDSYM, SMODES, and COMSUBS.

Download and Set-Up

  • Create a directory, isobyu, to contain the program and data files.
  • Download iso.zip (about 11 MB) into that directory.
  • Unzip the files using the command, "unzip iso.zip".
  • You may delete iso.zip.
  • Add an environment variable ISODATA which contains the full path to the isobyu directory. For example, if the full path is /usr/local/common/isobyu/, then the command in c shell would be: "setenv ISODATA /usr/local/common/isobyu/". Be sure to put a forward slash (/) at the end.
  • Everything should be ready to run. Try running ISOTROPY by entering the command, iso.
