# 架构迁移的数学合同与证明

本文件是本项目的可审查推导，非外部文献结论、形式化软件认证或全晶体保证。
本轮实际审读 `latex/isodistort_theoretical_foundations.tex` 的 `sec:affine`、
`prop:affine` 与 `unsupported_algorithm_proofs.tex` 的 `sec:modes`。
以下推导将其中列基约定明确转换成 pymatgen/GD 使用的行基约定。
来源条目的审读状态仍以 `sources.json` 为准，不新增“已通读”声明。

## 1. Seitz 操作迁移保持群作用

设母相和子相分数坐标为列向量，子胞基矩阵 B 的行是母胞坐标下的子基矢，
子原点在母胞坐标下为 q。因此 x_p = Bᵀ x_c + q。假设 B 为可逆有理矩阵，
母相操作 g=(R,t) 和 q 均为精确有理数，则代入得：

R_c = (Bᵀ)⁻¹ R Bᵀ，t_c = (Bᵀ)⁻¹(Rq+t−q)。

证明：将 x_p 的表达式代入 Rx_p+t，再左乘 (Bᵀ)⁻¹ 并减去相应原点项，
即可逐项得到上述公式。记坐标仿射映射为 F，则 g_c=F⁻¹gF，
所以 (gh)_c=g_c h_c；恒等元、逆元及闭包在共轭下保持。
从子相原始平移格展开到惯用胞时，必须加入全部中心化平移余类；只加旋转不充分。
`backend/export/child_frame.py` 原样迁移原会话实现，以 `Fraction` 算术求上述式子，
拒绝重复操作，并与指定 Hall setting 的完整操作集交叉核对。
Hall 数据比对是额外检验，不代替上述证明。有限有理假设不包括任意带噪测量坐标。

验证覆盖非对角 B、非零 q 和精确操作集；已有 affine 群/格测试继续覆盖闭包、
平移余类及原/惯用胞合同。精确路径不使用浮点“匹配容差”。

## 2. GD 倒易变换及反例

直接晶格按行存储，A_c=B A_p。位置按行存储，r=x_c A_c=x_c B A_p，
因此未移动子原点的基超胞坐标满足 x_p=x_c B。Miller 指数也按行，
衍射相位是 2π h_p x_pᵀ。代入即得

h_p x_pᵀ = h_p Bᵀ x_cᵀ；故 h_c=h_p Bᵀ。

旧 GD 用 h_p B。对角 B 有 B=Bᵀ，因此旧 LD 对角例子不能区分两算法。
取 B=((1,1,0),(0,1,0),(0,0,1))、h_p=(2,−1,3)，
则正确 h_c=(1,−1,3)，旧值=(2,1,3)。取 x_c=(0.1,0.1,0.3)，
正确相位内积为 0.9，旧值为 1.2。这是与材料无关的最小反例。
修复 `_hkl_transform_from_basis` 为返回 Bᵀ；不得默默用单位阵替代坏矩阵。
带原点位移时还应有常相位 h_p qᵀ；本接口明确提供“原点移动前”的基超胞，
没有省略已应用的 q。若消费者另行改变原点，须自行按该式处理。

## 3. 结果快照与归一化

`DisplacementSnapshot` 携带完整候选身份、nmod、计算上下文、行基 A（Å）、
分数坐标、物种和有序模式列。列、标签、符号、原子次序和原始尺度均逐项复制，
用不可变 tuple 存储。它不重新求解、不排序、不拟合、不换相位，也不提供官网答案。
身份缺失、孤立列、非有限值、重复键或计算后候选/nmod 改变时拒绝输出。

令一个非零原始分数位移列为 U，N 为本接口声明的“所表示母胞”数量，
S=Σ_j ||U_j A||²>0，取基准长度 ℓ₀=1 Å。缩放为 V=U ℓ₀ sqrt(N/S)，
因此 Σ_j||V_j A||²/N=ℓ₀²=1 Å²，V 仍是无量纲分数位移。
代码中的 A、S、d_max 使用 Å 及 Å² 的数值，故 ℓ₀ 的数值为 1。
先除最大分量再归一化的中间步骤会代数消去，不会改变列的符号。
无量纲 GD 系数 a 给出分数位移 aV；多列叠加 Σ_i a_i V_i，
快照逐列保留意味着线性组合不变。令 d_max=max_j||V_j A||，
则无量纲上界 a_max=ℓ₀/d_max，且 a_max d_max=1 Å。
斜晶格必须使用 U A，不能对分数分量直接求欧氏范数。

旧实现对 max|U|≤1e−16 跳过第一步，并在 S/N≤1e−30 时把缩放设为 1；
U=(1e−20,0,0)、A=I、N=1 会错误输出均方位移 1e−40 而非 1。
现在所有有限非零列都进入同一归一化合同。零列、非有限输入、奇异晶格和无效 N
显式拒绝；已检测的不可表示尺度及必要分量的下溢也拒绝，不伪造单位因子。
数值实现令 m=max|U|、L=max|A|、C=(U/m)(A/L)、c=max|C|、Q=C/c、r=||Q||F。
则 S=m²L²c²r²，V=(U/m) sqrt(N)/(Lcr)，与上述公式完全一致。
`frexp/ldexp` 组合分母因子的二进制指数，避免先形成 Lcr 造成溢出/下溢；
最大笛卡尔位移由 Q sqrt(N)/r 计算，避免再次乘入极端尺度。
这里的重排只改变浮点求值顺序，不改变数学对象或坐标约定。
模式和晶格分别取 1e−300/1e300 的测试验证可表示的极端尺度；测试斜晶格数值良态，
rtol=2e−14 对应约 90 个双精度机器 epsilon，覆盖短点积、平方和和缩放的舍入。
这不是任意病态矩阵的统一前向误差保证。尺度/符号不变量及失败反例未放宽容差。

进一步反例取 A=diag(2e−24,1e300,1)、U=(1,0,3e−24)、N=1。
A₁₁/L 下溢为 0，另一笛卡尔分量舍入至最小 subnormal；只检查整列非零会错误接受，
实测返回 V 的 Σ||VA||²=0.5325667378703975，却给出振幅界 1。
实现现在逐步检查 U/m、参与点积的 A/L 分量、三个非零乘积、逐项和、C/c 及输出 V：
必要的非零乘除结果小于 binary64 最小正常数 2⁻¹⁰²²（包括变成 0）时明确拒绝。
结构零、整列模式都不使用的晶格行不属于丢失贡献；已经舍入的正常项相消成 0 不冒充下溢检测。
这是保守的支持域：即使某个 subnormal 恰好精确或影响很小，也不尝试猜测修补。

以输入的 binary64 值为数学数据，在正常结果的 round-to-nearest 模型中，
令 u=2⁻⁵³。检查基于舍入后值，为涵盖精确值刚低于最小正常数却舍入到该边界的情况，
单步保守采用 fl(x op y)=(x op y)(1+δ)、|δ|≤η=u/(1−u)。两次缩放除法、
一次乘法及三项点积的两次加法给出 C_jk 的分量绝对误差界
γ₅ Σ_i |(U_ji/m)(A_ik/L)|，γ₅=5η/(1−5η)。该界的细化不改变测试容差。
严重相消时绝对界不能推出小的相对误差；本轮不声称覆盖任意病态晶格。
新增正负号下溢反例和正常数边界反例验证拒绝域，原有良态极端尺度测试及容差保持不变。

这里 N=|det B|，只有正整数的“所表示母胞”指数受到本 GD 转换器支持；
精确有理行列式非整数时返回不支持，不再四舍五入或强制变成 1。
母胞若为中心化惯用胞，这个均方定义不能自动声称等于 ISO 原胞的 A_s/A_p。
本轮保持有效域内的数值缩放公式、修复阈值旁路并澄清该边界，没有用官网幅度反推转换因子。
跨项目测试用独立 P1 微观基、斜晶格、非对称 B、正负振幅验证列及位移回代。
GD 保存 float32，因此还必须在转换后的数组上验证形状、有限值、非零模式列、
正归一化因子/振幅界和非奇异晶格/HKL，以及实际生成的倒易晶格可表示性。
反例 A=10⁴⁰I 或 A=10⁻⁴⁰I（条件数均为 1）表明：双精度计算有限不能推出
单精度晶格或模式有限。这是存储可表示域限制，不是晶格病态或归一化公式的反例。
超域数据在返回 bundle 或写任何文件前被拒绝，不以裁剪/改零修复。
比较预算 rtol=2e−7、atol=2e−8 对应该序列的舍入；
精确格指数不用容差，双精度坐标复制检查 atol=1e−14、rtol=0。

## 4. 整数调制数与失效关闭

nmod 是计数；布尔值、浮点数、字符串和负值不能经 int()/默认零改成另一请求。
本实现声明支持 0..3；大于 3 显式返回不支持，取代旧的静默截断到 3。
这个上限是现有求解器的实现范围，不是“高维超空间不存在”的数学断言。
HTTP 文本先按整数语法解析，再与 Python API、Method 2 和 superspace 复用同一合同。

网页输入框也是文本边界。先去首尾空白，再要求整串满足 `[0-9]+`，之后才转换为
安全整数并检查 0≤nmod≤3。不得使用只读前缀的 `parseInt`：`1.9` 和 `1e1`
都会被它误读为 1。这里拒绝 `1.0`、指数表示、符号和空串，即使某些写法可表示整数，
它们也不属于本协议的十进制整数文本语法；前导零不改变数值。
对被接受的文本 s，s 的每位都是十进制数字，转换结果就是其十进制求值；
0..3 均可精确表示，因此没有舍入或容差。拒绝时保留之前已提交的 nmod，
不清空有效结果、不发送新的科学请求。该输入合同不扩大调制数的求解范围。

`select_path()` 与 `search_method_2()` 现在共用一个求解入口；前者明确传入当前 nmod，
保留物种作用域并返回同次求解的 PhasePath。删去旧的第二套分支不改变特殊 k 根模、
参数 k 或 exact_fixed_space 的数学定义；改变的是候选唯一性、诊断拒绝与结果状态的一致性。
修前最小反例分别证明重复序号被任选、未决路线进入计算、显式类型与快照上下文不一致。
修后在 nmod 0/1/3、全/H/He 作用域、默认/显式类型的组合上核对两公开入口的等价结果与身份。
作用域过滤只消费求解器输出，不再隐式启动另一套求解；它不能充当独立科学正确性证明。

## 5. 运行与证据合同

有状态计算/选择事务提交前的会话状态是 S，动作在独立复制的 S' 上计算。只有动作、响应构造及 UTF-8 JSON 编码均成功
才在锁内单次替换为 S' 并增加 revision；异常路径不替换 S。
运行目录和生成数据库也属于事务资源，须独立复制，不能因对象复制而共享可写目录。
上传新母相使用新的计算实例，只继承用户类型/作用域与 revision；原实例已失效也不阻止
重新上传。只有新输入加载及响应验证成功才替换旧状态，新输入失败仍保留旧输入和结果。
其余有状态计算/选择动作继续复制当前计算状态及生成数据库，保证同一输入的事务连续性。
`kpoints`、`irreps`、`method1_options` 查询及运行缓存管理在当前会话锁内执行，不复制 S 或增加 revision；
外部查询超时仍可使运行实例失效，需要新实例恢复。它们不属于上述状态发布事务。
此为程序状态不变量，无物理单位或数值容差。

跨进程运行资源的存续期须覆盖 Python 会话。本机 WSL `/tmp` 位于 tmpfs；
20 秒自然空闲反例中，Python wrapper 未关闭、finalizer 未调用，目录仍随发行版退出而消失。
同次实验位于持久 ext4 的 `/var/tmp` 对照目录保留。WSL 私有目录因此使用
`/var/tmp/id-XXXXXXXX`，仍由实例独占和回收，路径长度 20 字节满足已知短路径约束。
这是本机文件系统/生命周期实测，不保证用户主动删除、系统清理策略或磁盘故障时资源仍存在。

Windows 的 `subprocess.run(capture_output=True, timeout=...)` 在超时杀死直接子进程后，
仍可能无界等待被后代继承的输出管道 EOF。受控后代保持句柄即可构造反例。
运行器改用临时文件捕获和显式有界 wait；读取 fstat 所固定的当前长度，不等待后代关闭文件。
这保证本地已创建进程的等待路径有界，不包括操作系统的进程创建耗时，也不证明 Linux
后代已终止。超时实例失效关闭、禁止继续复用缓存；下一次必须新建独立运行目录。
不杀未知进程、不重启 WSL；清理每一步仍使用各自的超时，不能把单步的界当作整会话的界。

导出任务的 job_id、来源 revision、取消事件和终态由同一所有者管理；
旧任务不得更新/取消新任务，终态提交早于释放所有权；下载响应携带自己任务的终态，
不因后续任务替换轮询状态而把部分成功显示成全部成功。
严格比较的通过条件是语义匹配 ∧ 可信参考哈希匹配 ∧ 字节一致；
未提供可信哈希且未发现其他不匹配时是 inconclusive；已有差异仍为 fail。
不能从“没有发现哈希错误”推出“哈希已验证”。
解析、字节比较和 SHA-256 均来自一次不可变读取；该措施保证同源性，不证明文件来源真实。
来源必须仍由独立登记的可信指纹提供。

缓存复用还要求“被签名源码覆盖实际计算实现”。旧 Method 3/4 准备器只签名小列表，
单独改变参与求解的 `utils/affine_embeddings.py` 或 `base_wrapper.py` 不会改变签名，
可继续复用旧通过 checkpoint/已生成输入。共享 `production_source_paths` 现在登记全部
backend/application Python 源码，准备器额外签名运行配置、自身、验证代码及独立母相。
这会保守地使未实际调用模块的变化也失效，优先保证不会因职责迁移而漏掉真实实现。
临时源码副本上的变更反例验证签名变化和恢复拒绝；没有执行旧批次生成或改写其冻结输入。

### 5.1 动作策略与响应归属（2026-10-20 补充）

以下是本项目对程序不变量的推导。假设同一服务进程的共享会话由现有锁保护，
所有变更均经 `workflows.execute`；revision 是该进程内单调递增的整数，
不保证服务重启后与旧浏览器页面的 revision 可直接比较。

每个动作由不可变的 `(handler, policy)` 一次登记。policy 必须是明确的 LIVE、
TRANSACTION 或 REPLACE_PARENT；遗漏或非法策略在调用 handler 前报错。
LIVE 在锁内运行并返回当前 revision，不发布新的会话。两种事务策略分别复制当前会话
或创建新母相实例，并在响应编码成功后提交 revision+1。因此，对成功/失败次数归纳，
成功事务恰好前进一步，失败不发布，新增动作不能因漏填另一份清单而隐式进入 LIVE。
这不证明 LIVE 处理器不会改变运行缓存；缓存管理本来就属于该策略的声明合同。

令页面已接收版本为 R，请求发起版本为 b，响应来源版本为 r，同一视图请求域的序号为 j。
通常每个路径为一个请求域；缓存列表 GET 与删除 POST 因共用视图而使用同一域。
页面只在 r≥R 时考虑接收状态；结果消费者还要求 r 等于当前 R，且 j 仍为该域最新序号。
因此，迟到的较小 r 不能回退状态，同版本下较早的只读查询也不能覆盖较新的查询结果。
错误响应同样检查请求归属；失败不是绕过上述判据的理由。只读响应发现另一个版本时，
先取该版本的完整状态，不能拿不完整的查询数据补造状态。

已接收的本页连续事务满足 b=R、r=R+1 时，只有服务端明确保留的其他 Method 候选池
可以迁移到新版本；被此次搜索替换的池先清空，模式/分解结果失效。新母相、类型变更或
外部版本推进清空全部旧结果和选择项。候选操作检查表的所属版本，不能仅凭行号延用旧表。
兼容事务越过尚未完成的只读选择项查询时，只对仍属当前输入代次和最新请求的查询重试。

文件读取也是异步边界。daughter 在读取前固定母相 revision 和表单参数，读取后母相
改变则不提交；母相上传在同一页面内排队，过时的读文件任务不发 POST，已发出的任务
完成后才发下一个。故在同页队列且响应正常完成的条件下，后一次上传不会被前一次
较晚提交覆盖。此论证不提供跨标签页“最后点击优先”保证，也不将网络失联等同于服务端取消。

实际页面脚本由 Node 的受控 DOM/网络/文件时序反例检查上述条件，HTTP 定向检查另核对
传输及锁内 revision。它们不等于真实浏览器操作验收，也不证明上游晶体学结果正确。
这些合同无物理单位、浮点容差或新增晶体学近似；但它们保护科学输入和结果身份，
不能按纯展示修改豁免。

### 5.2 WSL 文本传输合同（2026-10-20 补充）

Microsoft WSL 0.64.0 的
[发布说明](https://github.com/microsoft/WSL/discussions/8641)声明 `WSL_UTF8=1`
控制 Windows 客户端输出编码；本次只审读该项及官方诊断脚本中的同名设置，
不把行为说明当作晶体学证明。本机 WSL 2.7.10.0 的原始字节对照确认：
未设置时，同一错误流包含 UTF-16LE 服务警告与 UTF-8 Linux 错误；子进程设置为 1 后，
同一诊断为 UTF-8。服务错误还可能只写 stdout，失败详情必须保留 stdout 和 stderr。

`_run_wsl_command` 仅给本次子进程的环境副本设置该值，不改变父进程或 Linux locale。
成功 stdout 按严格 UTF-8 解码并拒绝 NUL；既有首尾空白裁剪保持不变。
对于合法 UTF-8 字节串 b，解码后的文本重新编码满足 encode(decode(b))=b；
裁剪只应用原有协议边界，不对内部科学文本猜测编码、删零或替换非法字符。
非法或不支持的成功输出显式失败，不能进入后续科学解析器。这一支持域要求 WSL
客户端支持该设置；本轮没有证明所有旧版 WSL 或任意 Linux locale 的兼容性。

失败诊断与成功输出走不同合同：只兼容整流 BOM 声明的 UTF-16，以及独立的、
以编码后的换行或流末尾结束的 ASCII UTF-16LE/BE 记录。其余字节使用 UTF-8 并显式
转义非法字节和 NUL，不声称可恢复任意无 BOM 本地化混合编码或行中交错编码。
该回退仅解释错误信息，不能成为成功结果的数据通道。原生非 WSL 路径未修改。
精确字节/文本相等、非法编码拒绝和真实 WSL shell 测试验证传输合同；
没有数值容差，也没有运行科学二进制或读取官网答案。

### 5.3 导出选择完整性与取消回调所有权（2026-10-20 补充）

候选池 C 是在会话锁内取得的有序列表，q(c) 是当前池中的候选序号，
显式请求 W 是通过严格非负整数文本解析后去重得到的集合。选中序列定义为
S=[c∈C | q(c)∈W]，顺序仍来自 C，不来自客户端列出的顺序。
只有 W⊆q(C)，且每个 w∈W 在 C 中恰好出现一次，选择才完整且无歧义。
证明：包含关系保证每个请求至少有一个像，唯一性保证至多一个像，因此
W 与 S 逐个对应且 |S|=|W|。直接求交集只保证 S 不含额外元素，
不能推出所有 W 都得到满足；W={1,999}、q(C)={1} 是最小反例。

未提供 indices 时取整个池；此时整个被选池必须序号唯一。显式空值是无效请求，
不能等价为“全部”。重复写同一请求序号遵循集合去重，不重复导出；未被选中的
另一序号有重复，不影响这个合法子集。候选完整科学身份仍由既有模型和快照保存，
序号只在固定 Method、revision 和候选池中作为选择入口，不能跨上下文作为全局身份。
缺失、歧义与非法请求必须在启动导出任务和创建计算快照之前拒绝，
因此失败不消耗 job_id、不覆盖既有任务状态、不开始科学计算。空候选池仍报无可用结果。

取消操作在发出请求前固定当前任务 J。响应 promise 与这次 HTTP 请求关联；
成功和失败回调写 UI 的必要条件均为当前仍在导出、activeExportJobId=J，
且该取消请求仍是最新的取消操作。最后一项防止同一任务两次请求的旧错误覆盖新成功。
如果当前已换成 K≠J 或已结束，判据为假，旧回调就不能改变进度或按钮。
这证明的是前端显示的任务所有权；后端仍以相同 J 与当前活动任务核对后才设置取消事件。
取消请求成功表示已请求在候选边界停止，不证明任务已停止；最终 ZIP/终态仍是完成依据。
轮询或下载响应确认与 J 匹配的终态时，立即清除活动取消身份并隐藏取消按钮。
这一步早于读取 ZIP 正文；否则终态已显示而 blob 尚在读取时，旧取消响应仍可能
通过“当前正在下载”的检查。终态退役与普通任务更换使用同一个身份，不另造取消任务。
`cancellation_requested=false` 不能推出任务终止：导出请求等待会话锁、尚未登记 J 时，
取消接口也会返回 false，而 J 随后仍可启动。因此，false 响应且请求仍拥有当前 UI
时允许重试；只有匹配的终态可以退役身份。迟到 false 遇到新任务或终态仍由所有权判据拒绝。
无需从响应猜测新任务身份或扩大服务端取消权限。

以上是输入/选择/异步归属的程序合同，使用整数、集合及身份精确相等，无物理单位或
浮点容差；不改变晶格、群作用、模式基或归一化公式。独立科学验证和真实浏览器验收
不由这些工程反例替代。

### 5.4 Method 2 草稿、查询池与模式归属（2026-10-20 补充）

本节是程序状态合同的本项目推导，不新增 k 向量求值、群作用或模式构造公式。
页面尚未提交的 k 选择与 a/b/g 文本为草稿 D；服务器当前版本 r 中的 Method 2
候选有序列表为 C₂；选中候选计算出的模式为 M。C₂ 是 Method 2 导出的唯一候选来源，
M 是派生结果，不能反过来充当查询池。尤其 C₂=∅ 是有效查询结果，不能解释成

却导出旧 GM，是这个错误回退的最小反例。候选标签只用于描述反例，生产规则不按标签分支。

空列表与非空列表遵循同一发布步骤。查询、序列化或响应编码失败不提交副本，原会话
及 r 保持。故按成功事务次数归纳，任何已提交 C₂ 都对应最后一次成功的 Method 2

前端复用现有 `/api/subgroups` 请求序号 q 表示本页查询代次。每次 k change 或
a/b/g input 都推进 q，并清空 Method 2 表的数据、所属 revision 和筛选状态。
开始新查询也执行同一失效操作，故未编辑参数直接重试、重试失败时也不会留下隐藏旧池。
改回原文本仍发生一次编辑，q 继续推进，不能仅凭文本相等恢复旧结果。
开始查询时捕获 q₀；发布候选需同时满足既有响应/revision 检查与 q=q₀。
从 Method 2 表发起的模式计算也捕获这个依赖序号，其成功、错误及后续显示都遵守
同一条件。旧派生模式按来源归属失效，不能误清来自其他 Method 的有效模式。

在单个页面的事件循环内，如果编辑先于旧响应的结果消费，q 已改变，旧结果的
发布条件必为假；若旧结果先显示，后续编辑会清除它。两种次序均不能留下
“当前新草稿下可操作的旧 Method 2 候选”。服务器已提交的 revision 仍正常接收，
过时结果不显示不等于服务器未执行，不能为丢弃旧 payload 而回退会话版本。
已提交旧查询导致服务端池失效时，仍清除相应候选数据，但不覆盖较新草稿的提示或忙碌视图。
另一事务可能先交付当前错误响应所携带的版本 r。此时请求的发起版本小于页面版本，
但不能据此认定错误过时：若错误携带完整 state、r 等于页面当前版本，且输入代次未变，
就应进入现有请求序号/查询依赖检查。只有仍拥有当前请求的消费者可以显示错误。
反例是旧模式请求先提交 r+1，当前查询随后收到同版本的 409；必须显示冲突并允许重试。
较旧版本在前置版本检查拒绝，较旧请求或已失效查询依赖在统一归属检查拒绝；
没有因为允许当前错误而放宽旧候选结果的有效性。
这也不提供跨标签页最后编辑优先的保证；跨标签页仍由服务器 revision 冲突处理。

合法下载在发出时固定 Method、revision、候选选择及服务器导出快照，后续草稿编辑
不追溯修改已经发出的任务；新下载必须重新满足当前候选表有效条件。没有把未提交
草稿塞入导出请求，没有新增猜测输入或官网答案通道。

检验使用整数序号、集合/列表及对象身份精确比较，不引入浮点容差。
输入参数的单位、分数求值、坐标、晶格对偶、归一化和科学支持域保持原合同；
本节不改变这些数学对象，因此不新增群闭包、守恒或数值误差证明。

### 5.5 数值配置不能由逻辑开关隐式产生（2026-10-20）

本节给出配置输入域的本项目推导，不改变对称性识别或有限搜索公式。
容差 τ 的合同为给定单位中的有限正数；Cartesian 容差单位为 Å，角度容差为度，
分数坐标和整数矩阵残差为无量纲。计数上限 N 为非负整数，其中配置明确允许的
N=0 才表示无限额；商群阶上限另要求 N≥1。逻辑开关属于布尔域 B，不属于这些
有尺度/计数意义的输入域，即便 Python 将 bool 实现为 int 的子类。

修前转换 float(True)=1.0 把开关变成 1 Å、1 度或无量纲 1；
int(False)=0 则可能无意撤销有限搜索上限。转换后的数满足旧范围判断，
所以仅在转换后检查正性/非负性不能拒绝原始非法输入。
必要顺序为：先拒绝原始布尔类型，再执行既有数值解析与有限性/范围判断。
因此合法数值的解析结果与原实现逐值相同，非法开关不会进入科学计算或控制搜索界限。
这不引入新默认值，不把字符串近似解释为晶体学参数，也不放宽数值容差。

实现由 `Config._positive_default_float` 与 `_nonnegative_runtime_int` 各自承担唯一
输入校验；属性、历史名称和缺省回退继续共用这两个入口。检查覆盖全部相应数值属性、
True/False、合法整数/小数/数值字符串，以及显式 0 哨兵。
正反例采用解析值精确相等和异常拒绝，没有浮点比较误差预算的变化。
本节不改变群作用、晶格对偶、轨道或守恒公式；不能把配置拒绝测试当作这些算法的验收。

### 5.6 查询、模式基和分解的统一归属（2026-10-20）

本节将第 5.4 节的请求代次合同应用到所有结果查询，并补齐模式基的消费条件。
这是本项目的程序状态推导，不是外部文献定理，也不证明既有模式求解器正确。

记 Method j 的请求代次为 qⱼ、候选或幅度列表为 Cⱼ、列表所属会话版本为 rⱼ。
开始替换查询时先推进 qⱼ，再同时清除 Cⱼ、rⱼ 和筛选状态，最后才显示忙碌或错误。
于是即使新查询失败、服务器正确回滚到旧会话，页面也没有可静默下载的隐藏旧池。
每个结果只能在请求序号、来源依赖与会话版本均符合已有响应合同后发布。
旧成功请求可能已在服务器提交新版本；接收这个事实不能恢复旧 payload，
也不能擦掉新请求的忙碌或错误提示。数据失效和是否保留当前提示由同一归属判断决定。

传输失败、JSON 解析失败或非对象 JSON 没有可信的服务器版本。
它们被规范为仅含失败信息的本地响应，以请求序号、来源查询依赖及输入 generation
判断是否仍属于当前操作，不伪造 state/revision，也不调用服务器状态发布路径。
因此另一兼容事务先推进 revision，不会单凭版本差吞掉当前网络错误；
而新请求、来源查询失效或输入 generation 改变仍会丢弃旧错误。
服务器成功 payload 和携带 state 的错误仍严格遵守原版本合同。
这一分支只处理错误提示，不能发布候选、模式或成功状态。
已发 ZIP 有独立快照生命周期：页面换母相不取消该下载，故其本地传输或 blob
读取失败由仍有效的导出请求/任务生命周期决定是否显示，而不套用普通查询的
输入 generation。已被替换或结束的下载不能写新任务反馈；这不放宽任何服务器
旧版本 payload 的接收条件，也不把已完成计算误当作文件已经下载成功。

模式计算 B 复用 `/api/method2` 的请求上下文，并记录其来源查询 qⱼ。
页面只保存一个已接受上下文 `selectedModeContext`，不另行维护第二份候选/nmod 身份。
开始另一次模式选择即清除该上下文；失败不能恢复上一选择。
已生效 nmod 改值推进模式请求代次并清除模式与幅度结果；重复提交相同合法值不改变身份。
模式请求从任一 Method 发起，都依赖对应查询代次，因此来源查询被替换后，
在途模式也失去发布资格。父结构/类型的成功变更仍由既有全局上下文失效处理。

Method 4 在读 daughter 文件前固定 B 的对象身份、模式请求代次及会话版本；
文件读取完成后和响应消费前分别检查。两次 await 之间若选择另一候选、修改 nmod、
替换 B 的来源查询或更换父结构，至少一项必要条件变假，旧 daughter 不能获得新基的归属。
成功的 Method 4 只消费 B，不改变它：清除模式的展示行并不等于丢弃基，
连续使用同一基分解多个 daughter 仍合法。相反，模式行数不能充当基存在的判据；
空的展示列表和实际计算上下文是不同对象。

服务端的权威模式基由既有 `_mode_cache_key` 绑定：

`K = (嵌入身份, nmod, 规范类型集合, 各启用原子类型的解析物种集合)`。

`displacement_snapshot` 与 `search_method_4` 共用 `_require_current_mode_context`，
要求已选候选及已提交 K 存在，并且按当前输入重建的 K′ 与 K 精确相等。
检查在读取 daughter 或调用分解器之前发生；它不通过重算、拟合或回填来修补失配。
网页提交的可选 nmod 还须等于已提交基的 nmod；旧 Python/HTTP 调用者省略该字段时，
仍检查完整 K，不放弃上下文校验。输入字段仅用于断言已有基，没有增加自动重算路径。
公开加载入口清除旧基；直接篡改私有结构/缓存不属于该合同的支持用法。

若仅以“有非空模式数组”放行，改变 scope 或 nmod 后数组仍可能非空，
却代表 K 而非 K′，因此该条件不足。反例是 H-only 基在范围改为 He 后仍进入分解器，
或者 nmod=0 的基被 nmod=1 的请求消费。精确 K 比较在分解前拒绝二者。
页面另有独立职责：A 选择成功、B 选择失败时服务器回滚保留 A 是正确的，
但页面不能把 A 偷换成 B 的基；单个已接受请求上下文确保此时 Method 4 不发出请求。
因此页面的操作意图与服务器的科学基身份检查互补，不能互相替代。

所有归属检验均为整数、集合、元组和对象身份的精确比较，无新浮点容差。
未改变晶格行基、分数坐标、Å 制位移、应变定义、模式列、归一化或最小二乘公式。
已有 ZIP 在发出时固定的快照继续有效；输入变更只约束后续动作，不追溯改写快照。
测试区分失败/成功、当前/倒序响应、不同来源查询、读文件及消费响应间的变更、
相同/不同 nmod、同基连续分解和新选择失败，不依赖特定材料或候选标签分支。

### 5.7 显式空物种范围不得扩大为全部（2026-10-20）

设母相存在的物种集合为 S，某个启用原子畸变类型的显式选择为 L。
未给范围或显式通配符表示 S；普通列表解析为 P=L∩S。
这两种输入形式必须区分，特别是显式 `[]` 表示 P=∅，不等于没有指定范围。
将空列表写成通配符，或者把解析后的空集合作为 `species_filter=None` 传下去，
都可能把“无选中物种”扩大成 S。两种情况分别由 `[]` 和只含母相外物种的列表反证。

当前正式计算不承诺启用类型的零物种求解：若显式选择解析后 P=∅，
在启用或消费该原子类型时明确拒绝，要求选择物种或禁用该类型。
这保留了 P⊆S 的选择合同，并避免通过一个未经证明的零模式分支绕过计算。
未启用类型的空列表可以保存，便于页面表示 none；应变作用于晶格，
不依赖原子物种列表，所以不套用该拒绝条件。
有非空交集时仍使用既有交集语义，不凭元素名称改变算法。

`set_distortion_scope` 先在局部对象中校验范围映射的形式，再一次提交。
顶层 None/空映射及字段 None 保留未指定语义；合法列表/元组与 all 通配保持原意。
这里的 None 合同属于 Python setter；HTTP 保留既有更窄 JSON 输入域，
字段 null 不合法，省略整个 scope 或传顶层 null 则沿用会话原范围。
普通标量字符串、布尔/数值/对象、非法列表元素及未知类型键不能被静默丢弃，
因为丢弃会使消耗端把原本显式的非法输入误当作缺省 S。
拒绝前不修改旧 scope，避免 Python 直接调用失败后留下半份新配置。

`set_distortion_scope` 保留显式空列表；`_scope_species` 是物种集合解析和空集拒绝的唯一入口；
`set_distortion_types` 在提交启用类型前调用它。网页类型变更在既有事务副本中执行，
非法组合使整个动作回滚，state、revision、候选与缓存均不能只提交一部分。
Python 调用者可以存储禁用类型的空范围，但不能随后用它计算。
尚未加载母相时，S 尚未确定，不能将它当作已知空集合来否定一个非空声明。
因此允许先配置非空物种列表和类型，再加载结构；真正消费时仍用已加载 S
检查交集。显式空列表无需知道 S 即可判空，所以在加载前也不能启用。
工作流发布 setter 得到的规范范围，页面按同一“缺字段为全部、显式空为 none”
合同显示物种与状态摘要，避免合法的空映射在求解中表示全部、在界面中却显示 none。

集合判断没有数值容差，也不改变物种到独立物理 Wyckoff 轨道的映射、
晶格/原子单位、群作用、归一化或守恒关系。正反例覆盖缺省/通配符/部分物种、
显式空/解析后空、非法范围形式及拒绝原子性、启用/禁用类型、strain，以及事务成功/拒绝。
本节只证明输入不会被隐式扩大，不能代替各物理类型的科学支持与独立验收。

## 6. 适用范围

迁移本身不证明外部 ISO 二进制、全部 230 空间群、未实现物理表示或无限 k 范围正确。
Method 3/4 原有独立输入与有限界限缺口保持有效；缺证据仍标 unsupported/inconclusive。
独立比较器的数学实现不因“消除重复”而改为调用被验证的生产算法。
