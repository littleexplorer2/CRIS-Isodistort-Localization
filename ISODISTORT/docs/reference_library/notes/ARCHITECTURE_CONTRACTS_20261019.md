# 架构迁移的数学合同与证明

本文件是本项目的可审查推导，非外部文献结论、形式化软件认证或全晶体保证。
本轮实际审读 `latex/isodistort_theoretical_foundations.tex` 的 `sec:affine`、
`prop:affine` 与 `unsupported_algorithm_proofs.tex` 的 `sec:modes`。
以下推导将其中列基约定明确转换成 pymatgen/GD 使用的行基约定。
来源条目的审读状态仍以 `sources.json` 为准，不新增“已通读”声明。

## 1. Seitz 操作迁移保持群作用

设母相和子相分数坐标为列向量，子胞基矩阵 B 的行是母胞坐标下的子基矢，
子原点在母胞坐标下为 q。因此 x_p = Bᵀ x_c + q。假设 B 为可逆有理矩阵，
母相操作 g=(R,t) 和 q 均为精确有理数，则代入得：

R_c = (Bᵀ)⁻¹ R Bᵀ，t_c = (Bᵀ)⁻¹(Rq+t−q)。

证明：将 x_p 的表达式代入 Rx_p+t，再左乘 (Bᵀ)⁻¹ 并减去相应原点项，
即可逐项得到上述公式。记坐标仿射映射为 F，则 g_c=F⁻¹gF，
所以 (gh)_c=g_c h_c；恒等元、逆元及闭包在共轭下保持。
从子相原始平移格展开到惯用胞时，必须加入全部中心化平移余类；只加旋转不充分。
`backend/export/child_frame.py` 原样迁移原会话实现，以 `Fraction` 算术求上述式子，
拒绝重复操作，并与指定 Hall setting 的完整操作集交叉核对。
Hall 数据比对是额外检验，不代替上述证明。有限有理假设不包括任意带噪测量坐标。

验证覆盖非对角 B、非零 q 和精确操作集；已有 affine 群/格测试继续覆盖闭包、
平移余类及原/惯用胞合同。精确路径不使用浮点“匹配容差”。

## 2. GD 倒易变换及反例

直接晶格按行存储，A_c=B A_p。位置按行存储，r=x_c A_c=x_c B A_p，
因此未移动子原点的基超胞坐标满足 x_p=x_c B。Miller 指数也按行，
衍射相位是 2π h_p x_pᵀ。代入即得

h_p x_pᵀ = h_p Bᵀ x_cᵀ；故 h_c=h_p Bᵀ。

旧 GD 用 h_p B。对角 B 有 B=Bᵀ，因此旧 LD 对角例子不能区分两算法。
取 B=((1,1,0),(0,1,0),(0,0,1))、h_p=(2,−1,3)，
则正确 h_c=(1,−1,3)，旧值=(2,1,3)。取 x_c=(0.1,0.1,0.3)，
正确相位内积为 0.9，旧值为 1.2。这是与材料无关的最小反例。
修复 `_hkl_transform_from_basis` 为返回 Bᵀ；不得默默用单位阵替代坏矩阵。
带原点位移时还应有常相位 h_p qᵀ；本接口明确提供“原点移动前”的基超胞，
没有省略已应用的 q。若消费者另行改变原点，须自行按该式处理。

## 3. 结果快照与归一化

`DisplacementSnapshot` 携带完整候选身份、nmod、计算上下文、行基 A（Å）、
分数坐标、物种和有序模式列。列、标签、符号、原子次序和原始尺度均逐项复制，
用不可变 tuple 存储。它不重新求解、不排序、不拟合、不换相位，也不提供官网答案。
身份缺失、孤立列、非有限值、重复键或计算后候选/nmod 改变时拒绝输出。

令一个非零原始分数位移列为 U，N 为本接口声明的“所表示母胞”数量，
S=Σ_j ||U_j A||²>0，取基准长度 ℓ₀=1 Å。缩放为 V=U ℓ₀ sqrt(N/S)，
因此 Σ_j||V_j A||²/N=ℓ₀²=1 Å²，V 仍是无量纲分数位移。
代码中的 A、S、d_max 使用 Å 及 Å² 的数值，故 ℓ₀ 的数值为 1。
先除最大分量再归一化的中间步骤会代数消去，不会改变列的符号。
无量纲 GD 系数 a 给出分数位移 aV；多列叠加 Σ_i a_i V_i，
快照逐列保留意味着线性组合不变。令 d_max=max_j||V_j A||，
则无量纲上界 a_max=ℓ₀/d_max，且 a_max d_max=1 Å。
斜晶格必须使用 U A，不能对分数分量直接求欧氏范数。

旧实现对 max|U|≤1e−16 跳过第一步，并在 S/N≤1e−30 时把缩放设为 1；
U=(1e−20,0,0)、A=I、N=1 会错误输出均方位移 1e−40 而非 1。
现在所有有限非零列都进入同一归一化合同。零列、非有限输入、奇异晶格和无效 N
显式拒绝；已检测的不可表示尺度及必要分量的下溢也拒绝，不伪造单位因子。
数值实现令 m=max|U|、L=max|A|、C=(U/m)(A/L)、c=max|C|、Q=C/c、r=||Q||F。
则 S=m²L²c²r²，V=(U/m) sqrt(N)/(Lcr)，与上述公式完全一致。
`frexp/ldexp` 组合分母因子的二进制指数，避免先形成 Lcr 造成溢出/下溢；
最大笛卡尔位移由 Q sqrt(N)/r 计算，避免再次乘入极端尺度。
这里的重排只改变浮点求值顺序，不改变数学对象或坐标约定。
模式和晶格分别取 1e−300/1e300 的测试验证可表示的极端尺度；测试斜晶格数值良态，
rtol=2e−14 对应约 90 个双精度机器 epsilon，覆盖短点积、平方和和缩放的舍入。
这不是任意病态矩阵的统一前向误差保证。尺度/符号不变量及失败反例未放宽容差。

进一步反例取 A=diag(2e−24,1e300,1)、U=(1,0,3e−24)、N=1。
A₁₁/L 下溢为 0，另一笛卡尔分量舍入至最小 subnormal；只检查整列非零会错误接受，
实测返回 V 的 Σ||VA||²=0.5325667378703975，却给出振幅界 1。
实现现在逐步检查 U/m、参与点积的 A/L 分量、三个非零乘积、逐项和、C/c 及输出 V：
必要的非零乘除结果小于 binary64 最小正常数 2⁻¹⁰²²（包括变成 0）时明确拒绝。
结构零、整列模式都不使用的晶格行不属于丢失贡献；已经舍入的正常项相消成 0 不冒充下溢检测。
这是保守的支持域：即使某个 subnormal 恰好精确或影响很小，也不尝试猜测修补。

以输入的 binary64 值为数学数据，在正常结果的 round-to-nearest 模型中，
令 u=2⁻⁵³。检查基于舍入后值，为涵盖精确值刚低于最小正常数却舍入到该边界的情况，
单步保守采用 fl(x op y)=(x op y)(1+δ)、|δ|≤η=u/(1−u)。两次缩放除法、
一次乘法及三项点积的两次加法给出 C_jk 的分量绝对误差界
γ₅ Σ_i |(U_ji/m)(A_ik/L)|，γ₅=5η/(1−5η)。该界的细化不改变测试容差。
严重相消时绝对界不能推出小的相对误差；本轮不声称覆盖任意病态晶格。
新增正负号下溢反例和正常数边界反例验证拒绝域，原有良态极端尺度测试及容差保持不变。

这里 N=|det B|，只有正整数的“所表示母胞”指数受到本 GD 转换器支持；
精确有理行列式非整数时返回不支持，不再四舍五入或强制变成 1。
母胞若为中心化惯用胞，这个均方定义不能自动声称等于 ISO 原胞的 A_s/A_p。
本轮保持有效域内的数值缩放公式、修复阈值旁路并澄清该边界，没有用官网幅度反推转换因子。
跨项目测试用独立 P1 微观基、斜晶格、非对称 B、正负振幅验证列及位移回代。
GD 保存 float32，因此还必须在转换后的数组上验证形状、有限值、非零模式列、
正归一化因子/振幅界和非奇异晶格/HKL，以及实际生成的倒易晶格可表示性。
反例 A=10⁴⁰I 或 A=10⁻⁴⁰I（条件数均为 1）表明：双精度计算有限不能推出
单精度晶格或模式有限。这是存储可表示域限制，不是晶格病态或归一化公式的反例。
超域数据在返回 bundle 或写任何文件前被拒绝，不以裁剪/改零修复。
比较预算 rtol=2e−7、atol=2e−8 对应该序列的舍入；
精确格指数不用容差，双精度坐标复制检查 atol=1e−14、rtol=0。

## 4. 整数调制数与失效关闭

nmod 是计数；布尔值、浮点数、字符串和负值不能经 int()/默认零改成另一请求。
本实现声明支持 0..3；大于 3 显式返回不支持，取代旧的静默截断到 3。
这个上限是现有求解器的实现范围，不是“高维超空间不存在”的数学断言。
HTTP 文本先按整数语法解析，再与 Python API、Method 2 和 superspace 复用同一合同。

`select_path()` 与 `search_method_2()` 现在共用一个求解入口；前者明确传入当前 nmod，
保留物种作用域并返回同次求解的 PhasePath。删去旧的第二套分支不改变特殊 k 根模、
参数 k 或 exact_fixed_space 的数学定义；改变的是候选唯一性、诊断拒绝与结果状态的一致性。
修前最小反例分别证明重复序号被任选、未决路线进入计算、显式类型与快照上下文不一致。
修后在 nmod 0/1/3、全/H/He 作用域、默认/显式类型的组合上核对两公开入口的等价结果与身份。
作用域过滤只消费求解器输出，不再隐式启动另一套求解；它不能充当独立科学正确性证明。

## 5. 运行与证据合同

有状态计算/选择事务提交前的会话状态是 S，动作在独立复制的 S' 上计算。只有动作、响应构造及 UTF-8 JSON 编码均成功
才在锁内单次替换为 S' 并增加 revision；异常路径不替换 S。
运行目录和生成数据库也属于事务资源，须独立复制，不能因对象复制而共享可写目录。
上传新母相使用新的计算实例，只继承用户类型/作用域与 revision；原实例已失效也不阻止
重新上传。只有新输入加载及响应验证成功才替换旧状态，新输入失败仍保留旧输入和结果。
其余有状态计算/选择动作继续复制当前计算状态及生成数据库，保证同一输入的事务连续性。
`kpoints`、`irreps`、`method1_options` 查询及运行缓存管理在当前会话锁内执行，不复制 S 或增加 revision；
外部查询超时仍可使运行实例失效，需要新实例恢复。它们不属于上述状态发布事务。
此为程序状态不变量，无物理单位或数值容差。

跨进程运行资源的存续期须覆盖 Python 会话。本机 WSL `/tmp` 位于 tmpfs；
20 秒自然空闲反例中，Python wrapper 未关闭、finalizer 未调用，目录仍随发行版退出而消失。
同次实验位于持久 ext4 的 `/var/tmp` 对照目录保留。WSL 私有目录因此使用
`/var/tmp/id-XXXXXXXX`，仍由实例独占和回收，路径长度 20 字节满足已知短路径约束。
这是本机文件系统/生命周期实测，不保证用户主动删除、系统清理策略或磁盘故障时资源仍存在。

Windows 的 `subprocess.run(capture_output=True, timeout=...)` 在超时杀死直接子进程后，
仍可能无界等待被后代继承的输出管道 EOF。受控后代保持句柄即可构造反例。
运行器改用临时文件捕获和显式有界 wait；读取 fstat 所固定的当前长度，不等待后代关闭文件。
这保证本地已创建进程的等待路径有界，不包括操作系统的进程创建耗时，也不证明 Linux
后代已终止。超时实例失效关闭、禁止继续复用缓存；下一次必须新建独立运行目录。
不杀未知进程、不重启 WSL；清理每一步仍使用各自的超时，不能把单步的界当作整会话的界。

导出任务的 job_id、来源 revision、取消事件和终态由同一所有者管理；
旧任务不得更新/取消新任务，终态提交早于释放所有权；下载响应携带自己任务的终态，
不因后续任务替换轮询状态而把部分成功显示成全部成功。
严格比较的通过条件是语义匹配 ∧ 可信参考哈希匹配 ∧ 字节一致；
未提供可信哈希且未发现其他不匹配时是 inconclusive；已有差异仍为 fail。
不能从“没有发现哈希错误”推出“哈希已验证”。
解析、字节比较和 SHA-256 均来自一次不可变读取；该措施保证同源性，不证明文件来源真实。
来源必须仍由独立登记的可信指纹提供。

缓存复用还要求“被签名源码覆盖实际计算实现”。旧 Method 3/4 准备器只签名小列表，
单独改变参与求解的 `utils/affine_embeddings.py` 或 `base_wrapper.py` 不会改变签名，
可继续复用旧通过 checkpoint/已生成输入。共享 `production_source_paths` 现在登记全部
backend/application Python 源码，准备器额外签名运行配置、自身、验证代码及独立母相。
这会保守地使未实际调用模块的变化也失效，优先保证不会因职责迁移而漏掉真实实现。
临时源码副本上的变更反例验证签名变化和恢复拒绝；没有执行旧批次生成或改写其冻结输入。

## 6. 适用范围

迁移本身不证明外部 ISO 二进制、全部 230 空间群、未实现物理表示或无限 k 范围正确。
Method 3/4 原有独立输入与有限界限缺口保持有效；缺证据仍标 unsupported/inconclusive。
独立比较器的数学实现不因“消除重复”而改为调用被验证的生产算法。
运行回归、第三方依赖、真实 WSL、打包与剩余缺口在当前验证报告记录。
