# 信源、覆盖与证明审核

## 审核口径

可靠性优先次序为：原始方法论文及勘误；IUCr 标准/权威卷册；作者和项目官方文档；
独立同行评审实现；作者教程。搜索平台只负责发现。作者讲义和 Computing Commission
通讯不标为同行评审论文。International Tables 的出版入口不等于已经获得整本书。

50 条记录按 DOI/作品识别，镜像与搜索命中不重复计为新论文。Exa 的 79 个请求结果位置
来自 15 次检索，包含重复与无关命中；它不是 79 篇独立论文或全文阅读数。
Consensus 使用 search 后 fetch 复核；Undermind 使用语义检索、作者检索和 DOI 元数据。
详细平台状态见 `search_log.json`。没有把研究判断或证明委托给外部诊断模型。

## 已处理的冲突与误配

1. 旧 `/iso/references.php` 入口已失效，采用作者当前 `/references.php`。
   ISO-IR 和 ISO-MAG 也从官网实际链接纠正为 `irtables.php` 与 `magneticspacegroups.php`。
2. 逆 Landau 论文在 2001 年在线发布、归入 PRB 65 (2002)；超空间论文在线年份为 2016、
   卷期为 Acta A73 (2017)。正文书目使用卷期年份，不直接照抄平台年份。
3. COPL 短文的作者顺序采用原文及出版社的 Stokes、Hatch，未沿用汇总目录中的相反顺序。
4. Howard 1998/2002 的模糊 Crossref 检索返回了无关 ACS 附件，已拒绝这些候选。
   原论文 DOI 由 IUCr 卷期目录核实；2002 勘误与原文同时引用，保留更正的子群图关系。
5. Wagner–Schönleber 教程实际为 2009 年；初始错误的 2011 年路径已替换，出版社正文得到核验。
6. 官方帮助旧段落提到 ESD，而版本 5.5 记录移除 ESD。本文只证明固定线性模型的协方差传播，
   不据旧段落宣布当前网站提供该功能。
7. 官方旧应变描述与后续版本的归一化/施加方式变化并存。分数基对称乘子、笛卡尔应变、
   小应变与有限变形分别定义；不把局部代码公式未经核对就称为所有版本的官网规范。
8. 2017 论文引言将部分非公度微观基投影问题留待后续研究。针对性追加检索找到 ISO-IR
   表、作者模式论文及官方帮助，但未取得足以认证官网所有微观列约定的独立说明。
   补充论文给出函数作用/等变嵌入的严格构造，并保留站点相位、排序等输入义务。
9. IUCr 的 Superstructure 词条还含化学不同原子的轨道分裂条件；仅取其平移包含关系为
   辅助说明，不把完整术语定义泛化为全部位移畸变。

## 覆盖检查

范围由本次官方帮助快照界定，`coverage.json` 将 26 类主题连接到原始来源、两篇论文的
章节标签和本地模块。官网功能与 CRIS 当前网页功能分开：完整 Generate、Domains、
子群树和官网可视化的理论可收录，但后端目录存在不证明对应本地 UI 已实现。

两篇论文给出的完整局部证明包括：仿射换基、精确理想对称搜索的有限界、轨道与稳定子、
群不变内积与字符投影、精确稳定子判据、有理见证、耦合稳定子交、超胞/相位阶数、
谐波别名、周期最近像、带度量分解、基变换身份、平均幅度归一化、SPD 度量方程、
应变右作用、非公度函数表示与等变嵌入、陪集畴数、固定次数不变量、有限子群树、
平移消光和线性误差传播。例证脚本只对部分推导作独立数值/精确代数检查。

## 尚不能认证的事实

- **外部实现和表数据**：论文不逐行认证二进制；完整分类和表示表仍依赖正确输入。
- **列身份**：同一 irrep/子空间并不固定重复实例、符号、原点和官网的模式标签。
- **非公度截断**：生成元方法要求有限谐波空间封闭；无限展开的截断误差需正则性条件。
- **版本特定应变**：SPD 方程可证明唯一性，但不是笛卡尔应变定义或官网约定的自动证明。
- **噪声和退化**：容差改变空间群、匹配或秩时，固定线性模型的扰动界不再覆盖该变化。
- **界面与互操作**：未运行官网全量科学差分或 GUI；文件语法合法不证明全部消费者行为。

这些是下一次算法/实测验收需要满足的条件，不以未查明的假设填充成“已证明”。
本次交付是经过来源筛选和内部数学复核的技术文档；没有声称完成独立同行评审或形式化证明器验证。

## 获取与版权处理

作者官网与机构公开 PDF 保存在本地，原始文件用 SHA-256 标识。扫描件的提取文本过少时
标记为扫描件，未将空提取结果当作全文审读。若 PDF/出版社直接获取失败但 Exa 可读公开正文，
同时保留直接获取失败和正文核验状态；二者并不冲突。原始全文仅在本地保存，引用和中文原创
概括可版本管理；不绕过付费访问、证书校验或出版社限制。

编译、引用完整性、文件哈希、源码定位及数学例证的当前检查结果分别见
`validation.json`、`code_context.json`、`mathematical_examples.json`。
