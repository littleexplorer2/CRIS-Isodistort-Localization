# 理论与程序设计审查（2026-10-15—16）

## 结论与边界

当前程序不能笼统认定为“全部符合晶体学理论”。本轮沿输入、仿射嵌入、表示、模式、
分解和导出的调用链，检查了关键数学合同，发现并修复了实际反例；缺少物理表示的
occupational、rotational、magnetic 计算改为明确拒绝。已有位移和应变实现继续使用
经来源约束的模式列及数学计算，而不读取某个母相的官网答案来替换运行结果。

本报告不是逐行形式化验证、全部空间群表审定或官网全功能认证。26 个主题的逐项
状态、未覆盖条件见 [机器清单](implementation_audit.json)。论文和证明的主题覆盖，
不能转换为程序对所有晶体的通过率。现有真实网页批次和 GUI 缺口仍保留在开发计划。

审查对象是 CRIS 的本地功能及其直接科学依赖。选课工具、原始 CIF、官网存档、
比较黄金集和 `resources/isobyu/` 均未修改。资料库此前的文献整理结果保留。

## 证据链

主要理论入口为 [完整理论框架](../latex/isodistort_theoretical_foundations.tex) 的
`sec:affine`、`sec:symmetry`、`sec:k`、`sec:physical`、`sec:methods`，以及
[补充证明](../latex/unsupported_algorithm_proofs.tex) 的 `sec:stabilizer`、
`sec:lattice`、`sec:matching`、`sec:modes`、`sec:strain`、`sec:micro`。
具体章节标签由同目录覆盖清单校验；以实际 LaTeX 中的标签为准。

独立理论来源包括 Campbell 等的模式空间框架 [Campbell2006](https://doi.org/10.1107/S0021889806014075)、
Hatch 与 Stokes 的逆 Landau 方法 [Hatch2002](https://doi.org/10.1103/PhysRevB.65.014113)、
Stokes 等的超空间各向同性算法 [Stokes2017](https://doi.org/10.1107/S2053273316017629)，
以及 [IUCr 的 International Tables](https://it.iucr.org/)。
书目、取得材料与实际审读层级仍以 [sources.json](../sources.json) 为唯一来源；
没有把仅有出版入口的卷册或扫描件声称为已通读，也没有委派外部模型作科学判断。

## 已修复的确定性问题

### A01：官网结果反向进入生产算法

`application/session/core_api.py` 原来按晶格和原子坐标识别母相，扫描
`webpage_info/<母相>/2. ISODISTORT_ search.html`，再用网页中的显示基矢替换
`method1_options()` 的结果。虽然还检查候选数和格点类，这仍会让输出依赖是否保存了
该材料的答案，破坏官网比较的独立性。原网页测试同时要求与被读取的答案逐字相等。

已删除档案扫描、结构指纹匹配和结果回填。候选数、格点类和代表基矢由计算生成。
官网测试保留候选数与晶格等价检查，改为检查本地标签准确描述本地基矢，不再要求选择
同一个等价代表元。独立反例测试在调用期间禁止遍历三个参考数据目录。

OPD 复杂度排序只用于稳定显示顺序，其注释已撤销“所有母相遵循官网排序”的无证据断言。
排序不参与晶格等价或物理可达性判断。

### A02：非正交点群的晶格作用错误及浮点误合并

约定分数列坐标满足 `x' = R x`，超胞矩阵 `B` 的每一行是一条直接基矢。
逐行转置立即给出 `B' = B R^T`。同一晶格的充要条件为
`B1 B2^-1 ∈ GL(3,Z)`，即矩阵元素全为整数且行列式为 ±1。

原会话层及搜索层尝试 `B R` 和 `R B`。在正交轴中这容易被点群闭包掩盖，在六方轴
中会产生不同的轨道。独立反例取
`R=((0,-1,0),(1,-1,0),(0,0,1))`、`B=diag(3,1,1)`，母点群为 `{I,R,R²}`。
`B R^T` 应属于该轨道，`B R` 不属于；旧代码两项均判反。

另一个反例为单位阵上加剪切 `B[0,1]=100000000.1`。原 `allclose` 的默认相对容差
将它误当整数，即使体积相同也不是 GL(3,Z) 基变换。已统一调用 `backend/utils/lattice.py`
的有理数运算，搜索层的包含关系同样采用精确整数判据。输入本来是浮点时，仍受该模块
显式的有理重建合同约束；这不等于从任意测量数据恢复唯一精确晶格。

显示函数的 `limit_denominator(12)` 也已移除：`1/17` 不再被显示成 `1/12`。

### A03：占据率二分与夹取不构成占据率模式

旧 `OccupationalModeGenerator` 将坐标排序后分为前后两半，再把负半区设为
`1-amplitude`。空间群号相同不足以证明同一仿射子群、k、IR、OPD 或成分约束。
同一 Wyckoff 字母还可能包含不同物理轨道，不能按字母合并成一个模式。

反例：母相某位点占据率为 0.6，旧生成器在振幅为零时仍把它改为 1；
负半区的 `max(...,0.01)` 和振幅夹取也破坏线性模式叠加。这不是数值稳定性处理。
生成器的任意二分和旧引擎的占据率改写已删除。兼容入口保留，但非空占据率生成请求
抛出 `NotImplementedError`。未来实现需满足 `o=o0+Ua`、站点标量表示、成分约束、
给定子群不变性及物理占据范围；不能通过裁剪改变请求后继续宣布原模式成立。

### A04：极矢量不能代替转动或磁矩

位移的作用为 `Q u`；转动轴矢量为 `det(Q) Q w`；磁矩还带时间反演符号。
在反演 `Q=-I` 下，位移改变符号而轴矢量不变，已经构成无需材料数据的反例。
旧流程用 smodes 位移活性筛选 rotational，随后只把 `mode_type` 改名。
这些分支已移除；magnetic 的名称前缀也不再作为物理活性证明。

统一检查位于 `backend/method1/phase_path.py`。搜索与实际模式生成都明确拒绝这三类
未实现模型，包括与已实现类型混合的请求，避免只算部分类型却返回完整成功状态。
Method 3 的独立诊断表示仍可报告 unsupported；这不授权进入正式生成路径。

### A05：Wyckoff 字母不能由轨道重数猜出

轨道--稳定子定理给出重数，不给出标准表中的字母。旧 writer 在表查不到时采用
`multiplicity.bit_length()+2` 选择字母，没有晶体学依据，现已改为 CIF 的未知值 `?`。
SG139 的 `(0,1/2,0)` 也不再被一个仅检查 x、y 的分支误标为 d；d 分支必须满足其
实际轨道，而 c 由对应表项给出。Cmma 中不能把所有八重轨道一律当作 n。

进一步以 writer 实际 Hall setting 展开全部部分表种子，并用独立 spglib 数据库检查。
SG67/Hall316 的旧 c、d、f、h 四项确有错误：例如旧 c 坐标实际是 g，旧 d 的轨道重数
实际上为 8。用 ISOTROPY 9.6.1 的 `VALUE PARENT 67 / SHOW WYCKOFF VECTOR /
DISPLAY PARENT` 复核后，修正 c、d、f 坐标，删除伪 h 固定位置条目。修正后的 31 个
种子全部通过同 setting 的轨道重数和字母检查。此处修订的是标准分类元数据，没有
按材料或候选结果建立答案表。SG129 的初次差异是默认 origin choice 1 与 writer 的
choice 2 混用；改用实际 Hall409 后原表一致，未据此错误修改表项。

spglib 富化标签现在指定目标 Hall，并要求空间群、Hall、标准化矩阵 `P=I` 和原点
`p=0 (mod Z³)` 一致，才把字母附到未变换坐标上。依据其
[官方 dataset 定义](https://spglib.readthedocs.io/en/stable/dataset.html#transformation-matrix-and-origin-shift)，
`x_standard=P x_input+p`；只检查群号不足以授权直接套用标准字母。门禁的 `1e-8`
是无量纲恒等变换的舍入容差，关闭相对容差；不是用于扩大可接受结构误差的拟合参数。
未满足门禁时保留未知值。31 个种子的检查不认证所有自由参数、边界退化或全部 230 群，
这些仍是后续审定义务。

### A06：符号波矢丢失负号、常数项和参数耦合

旧参数函数只抽取单个参数的系数，甚至把 `-a+1` 当成系数 +1。于是 SG139 的 Y
在 `a=1/3` 时被写成 `(1/3,1/3,0)`，而公式本身给出 `(1/3,2/3,0)`。
此外，`KPointInfo` 把 `a` 与 `1-a` 当成两个自由参数。

现将原一变量仿射解析器归入唯一公共实现 `backend/utils/text_parser.py`，并扩展为
精确有理多变量表达式。自由变量按标识符去重；重复表达式不增加维数。
官网坐标 `k=Cp+c` 与 ISO 坐标 `k=Dq+d` 的换算解方程
`Dq=Cp+c-d`，用有理高斯消元检查满列秩、相容性，并回代核对全部三坐标。
可逆行变换保持解集，满列秩保证解唯一；不相容或非唯一时明确拒绝。
这适用于耦合参数，也不需要按 k 名称保存转换答案。

针对本地 ISO 实际输出，对登记的 SG123/139 全部 25 个参数 k 项进行一次精确坐标
回代检查，25 项通过。它证明这些模板及所选有理值的换算一致，不证明所有 k 域、
边界 IR、OPD 或模式计算均已验证。未登记空间群的界面直接使用 ISO 坐标约定。

### A07：稀疏代表行不能授权均匀复制或最近邻补位

旧 `DistortionMapper.map_modes_to_atoms()` 在只找到一条 BUSH 代表行时把同一向量
复制到整条母相轨道；多代表行匹配失败时则拿最近行补位。对于反演相关的两个站点，
全对称位移必须满足 `u(-r)=-u(r)`，所以一条非零代表行绝不推出两个站点同向。
原来的“uniform single rep”测试正好把这项未经证明的假设写成了成功预期。

正式会话现直接安装现有完整子胞模式，再做经双射核对的母胞投影；不先生成启发式
位移。旧公共函数保留为 identity-cell 适配器，调用同一完整 BUSH 映射，沿用其物理
距离、平移相位、来源、覆盖性和冲突检查。缺少代表行会报错，需要子胞的模式须使用
明确的子胞接口；有微观来源的调用还须传入对应 subgroup context。没有建立第二套
猜测算法。原成功测试补齐零位移代表行，错误的均匀复制预期改为拒绝不完整表。

完整映射保持既有界面最大母相分数位移范数归一化；这个约定不是任意坐标系下的物理
长度。正式导出仍须使用独立的笛卡尔列尺度和模式来源合同，不能据此冒称官网振幅。

## 保留的有理论依据的计算

- **有限群与稳定子**：`method3/inverse_landau.py` 校验群与表示同态，使用 Reynolds
  投影、有理基和逐点稳定子，检查 `Fix(H)≠0` 且 `Stab_G(Fix(H))=H`。这与补充证明一致；
  仅有固定空间维数增加没有被当成充分条件。
- **原胞、k-star 与相位**：精确晶格模块及 `utils/opd_format.py` 使用实际平移格与
  `R^-T` 倒易作用。中心化表是晶格分类数据，不是按材料保存的答案。
- **模式来源**：`models/iso_mode_models.py`、`method2/distortion_mapper.py` 和
  `method2/superspace.py` 将来源列、原子顺序、坐标架、符号比例和子空间证明分开。
  子空间相等不自动等于网站每列身份；未解析列继续拒绝导出。
- **Method 4**：使用真实晶格度量下的周期距离与物种相容的全局双射，再在固定模式
  矩阵上解最小二乘，检查秩并输出残差和条件数。这是理论定义的线性分解，不能仅因
  出现 `lstsq` 就叫作背答案拟合；同样，小残差不能证明配对、IR 身份或物理模型正确。
- **应变**：`method4/strain.py` 解对称正定方程 `M G M=H`；`strain_modes.py` 使用
  Sylvester 映射与工程剪切约定。度量共轭是右作用，固定空间计算不需把它冒称左表示。
  SPD 唯一性不认证全部网站版本的归一化、符号和应变名称。
- **非 Γ 回代**：单母胞实列只允许可证明的自共轭平移字符；一般复字符要求完整子胞
  列或成对实/复列的来源合同，不用 cosine 猜测缺少的 sine 或 OPD。

## 未完成的审定与验证

外部 ISO/SMODES/FINDSYM 二进制和表示/空间群表没有逐行重建认证；标准数据版本、
Hall/origin 对照和模式规范仍是输入义务。部分 CIF writer 的代表元与原点选择采用
排序规则，其完整 setting 证明还不足。没有用新的样例输出修补这些规则。

非公度有限谐波空间的封闭性、任意/多参数 k 搜索完备性、极端病态晶格下的容差、
全部混合占位、GUI 与消费者对 `?` 等字段的处理，均不能由本轮单元测试推出。
Domains/完整子群树/衍射可视化的理论收录不扩大本地产品范围。
